# Data Science & Generative AI Submissions

This repository contains all assignments, Python notebooks, data analysis, code and practical exercises developed as part of the Data Science & Generative AI module at the University of Warwick. 

## Assignments

### Assignment 1: Data and Feature Engineering in Pandas
This assignment presents basic data manipulation techniques using Python, Pandas, and NumPy. We create DataFrames from lists and dictionaries, organize data into rows and columns, explore how Pandas handles missing values and understand the differences between data structures.
